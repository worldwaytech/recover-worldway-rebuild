- Tour marketplace supplier (TravelShop Booking) lives in src/lib/travelshop/: resumable paginated sync into travelshop_tours (dedupe on external_id), customer DTOs only via catalogue.server.ts, supplier booking write is staff-only (staffSendTourToPartner) and gated by TRAVELSHOP_BOOKING_ENABLED + a verified paid payment + the probe-verified contract in booking-contract.ts (bookingGates ladder; customer booking opens only after Gates 4–5) — Bókun kept as history only, its sync hook disabled unless BOKUN_MARKETPLACE_ENABLED=true.
- Tour marketplace discovery (featured, best-selling, trending, Region→Country→City, country guides) is computed from travelshop_tours via server-only RPCs travelshop_explore / travelshop_catalogue_totals and catalogue.server.ts — guides use catalogue facts only, never written/AI content.
- Multi-day tour stay rules live in src/lib/engine/tour-stays.ts (pure): tour/activity/hotel dates come from actual arrival local date; tours with included accommodation never get duplicate hotel nights; pre/post-tour hotels are returned separately as AssemblyReport.optionalStays and never enter offers or totals.
- Multi-day TravelShop tours are priced per person by room occupancy (sng/dbl/trp) via roomBasedTotal in src/lib/travelshop/catalogue.server.ts; children on room-priced tours go to the desk — the API gives no child room rate.
- TravelShop supplier booking writes atomically claim the record (awaiting → in_progress) and mark timeouts as supplier_uncertain for staff reconciliation — never auto-retried, so one record can never create two supplier bookings.
